# 标签变量

标签设计器中的文本和二维码内容都支持 `{变量}` 占位符。未知变量会渲染为空字符串。

## 库存标签

| 变量 | 含义 |
|---|---|
| `{name}` | 零件名称 |
| `{ipn}` | 零件 IPN |
| `{description}` | 零件描述 |
| `{category}` | 分类（库存接口未返回时为空） |
| `{quantity}` | 当前库存数量 |
| `{batch}` | 批次号 |
| `{serial}` | 序列号 |
| `{location}` | 库位完整路径 |
| `{code}` | 服务器生成的库存条码，如 `INV-SI178` |
| `{qr}` | 二维码默认内容（同 `{code}`） |
| `{url}` | 网页端库存详情 URL |
| `{date}` | 生成标签的日期 |

## 零件标签

| 变量 | 含义 |
|---|---|
| `{name}` | 零件名称 |
| `{ipn}` | IPN |
| `{description}` | 描述 |
| `{category}` | 分类路径 |
| `{quantity}` | 总库存 |
| `{code}` | 服务器生成的零件条码 |
| `{qr}` | 二维码默认内容 |
| `{url}` | 网页端零件详情 URL |
| `{date}` | 日期 |

## 库位标签

| 变量 | 含义 |
|---|---|
| `{name}` | 库位名称 |
| `{description}` | 库位描述 |
| `{parent}` | 上级库位名称 |
| `{path}` | 完整路径 |
| `{items}` | 库位内库存项数量 |
| `{code}` | 服务器生成的库位条码 |
| `{qr}` | 二维码默认内容 |
| `{url}` | 网页端库位详情 URL |
| `{date}` | 日期 |

## 二维码内容

- `{qr}`：使用服务器条码（默认，推荐）。扫码后 InvenTree 能直接匹配对象。
- `{url}`：网页详情链接，适合手机浏览器扫码打开。
- 固定文本：如 `https://erp.bi7khi.xyz`。
- 任意变量组合：如 `{ipn}-{batch}`。

## 设计器操作

- 点击元素芯片选择元素；
- 在预览中拖动元素改变位置（相对于标签宽高的 0–1 坐标）；
- 文本：字号 1.5–6mm、粗体、左/中/右对齐；
- 二维码：尺寸 8–30mm；
- 纸张：25–70mm × 15–60mm；
- 每个模板（库存/零件/库位）独立保存，恢复默认会重置当前模板。
